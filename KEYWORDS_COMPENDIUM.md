# Warhammer 40,000 11th Edition — Keywords & Abilities Compendium

This compendium provides the official rules, definitions, and category groupings for all keywords and abilities in **Warhammer 40,000 11th Edition**. It serves as the single source of truth for UI tooltips, search filters, and datasheet card tags.

---

## 1. Weapon Abilities (Section 24)

Weapon abilities are denoted in brackets, e.g. `[BLAST]`.

| Ability | Ref | Summary | Full Rules Description |
| :--- | :---: | :--- | :--- |
| **`[ANTI]`** | 24.03 | Critical wound on unmodified wound roll of X+ against specified target keyword. | Weapons with [ANTI-KEYWORD X+] in their profile are designed to defeat specific opponents. Each time an attack is made with such a weapon against a target unit with the specified keyword, an unmodified wound roll of X+ scores a Critical Wound. |
| **`[ASSAULT]`** | 24.04 | Allows shooting even if the bearer's unit Advanced this turn. | Weapons with [ASSAULT] can be fired on the move. A unit that contains one or more models equipped with an [ASSAULT] weapon is eligible to shoot in your Shooting phase even if that unit Advanced this turn, though only models equipped with [ASSAULT] weapons can make attacks. |
| **`[BLAST]`** | 24.05 | Explosive ordnance. Adds attacks against large squads, cannot fire in Engagement Range. | Weapons with [BLAST] in their profile represent high-explosive payloads. Each time you determine how many attacks are made with a [BLAST] weapon, add 1 to the Attacks characteristic for every five models that were in the target unit in the Select Targets step (rounding down). Blast weapons cannot be used to make attacks against target units that are within Engagement Range of one or more friendly units. |
| **`[CLEAVE]`** | 24.06 | Sweeping strikes. Adds attack dice for every 5 models in the target unit. | With sufficient might or skill, warriors may sweep blades or talons through their foes in long lethal arcs. This ability always takes the form [CLEAVE X]. Each time you gather attack dice for a [CLEAVE] weapon, if you only selected one target for all of that weapon’s attacks, add X additional attack dice for every five models that were in the target unit in the Select Targets step (rounding down). |
| **`[CLOSE-QUARTERS]`** | 24.07 | Sidearm weapon that can be fired while locked in Engagement Range (identical to Pistol). | Weapons with [CLOSE-QUARTERS] can be fired at point-blank range while in Engagement Range of enemy units. A model equipped with a [CLOSE-QUARTERS] weapon can shoot with it even if its unit is within Engagement Range of enemy units. Identical in rules to [PISTOL]. |
| **`[DEVASTATING WOUNDS]`** | 24.10 | Critical wounds bypass armour and invulnerable saving throws. | Weapons with [DEVASTATING WOUNDS] can pierce almost any defense. A Critical Wound inflicted by an attack with this weapon cannot be saved against by armour or invulnerable saves — the target unit simply suffers the damage. |
| **`[EXTRA ATTACKS]`** | 24.11 | Bearer attacks with this weapon in addition to other melee weapons. | A model equipped with an [EXTRA ATTACKS] weapon can attack with it in addition to any other melee weapons it selects to fight with. The Attacks characteristic of an [EXTRA ATTACKS] weapon cannot be modified. |
| **`[HAZARDOUS]`** | 24.15 | Risk of weapon malfunction. Roll D6 per weapon used; roll of 1 destroys model or causes mortal wounds. | After resolving all attacks with [HAZARDOUS] weapons, roll one D6 for each [HAZARDOUS] weapon used. For each roll of 1, one model in the attacking unit equipped with that weapon suffers 3 mortal wounds (or is destroyed if it is a Character/Monster/Vehicle). |
| **`[HEAVY]`** | 24.16 | +1 to Hit rolls if the firing unit Remained Stationary this turn. | Heavy weapons require bracing. Each time an attack is made with an [HEAVY] weapon, if the attacking model’s unit Remained Stationary this turn, add 1 to that attack’s Hit roll. |
| **`[IGNORES COVER]`** | 24.18 | Target cannot gain the Benefit of Cover against these attacks. | Each time an attack is made with an [IGNORES COVER] weapon, the target cannot have the Benefit of Cover against that attack. |
| **`[INDIRECT FIRE]`** | 24.19 | Can target non-visible enemy units (-1 to Hit, target gains Benefit of Cover). | Weapons with [INDIRECT FIRE] can make attacks against targets that are not visible to the attacking model. If an attack is made against a target that is not visible, subtract 1 from the Hit roll and the target has the Benefit of Cover against that attack. |
| **`[LANCE]`** | 24.21 | +1 to Wound rolls if the bearer charged this turn. | Each time an attack is made with a [LANCE] weapon, if the bearer made a charge move this turn, add 1 to that attack’s Wound roll. |
| **`[LETHAL HITS]`** | 24.23 | Critical hits automatically wound the target. | Each time an attack is made with a [LETHAL HITS] weapon, a Critical Hit automatically wounds the target without needing a wound roll. |
| **`[MELTA]`** | 24.25 | Thermal armor-melting blast. Adds +X Damage at half range. | Weapons with [MELTA X] unleash blinding heat. Each time an attack made with a [MELTA X] weapon targets a unit within half that weapon’s Range, that attack’s Damage characteristic is increased by X. |
| **`[ONE SHOT]`** | 24.26 | Single-use weapon that can only be fired once per battle. | The bearer can only shoot with this weapon once per battle. |
| **`[PISTOL]`** | 24.27 | Can shoot in Engagement Range. Functionally identical to [CLOSE-QUARTERS]. | Weapons with [PISTOL] can shoot while their unit is in Engagement Range of enemy units, targeting those enemy units. Functionally identical to [CLOSE-QUARTERS]. |
| **`[PRECISION]`** | 24.28 | Attacking player can allocate successful attacks directly to a visible Character in an Attached unit. | When an attack made with a [PRECISION] weapon successfully wounds an attached unit, if a CHARACTER model in that unit is visible to the attacking model, the attacking player can allocate that attack directly to that CHARACTER model instead of the bodyguard unit. |
| **`[PSYCHIC]`** | 24.29 | Psychic manifestation weapon or attack, interacts with [ANTI-PSYKER]. | Weapons and abilities with the [PSYCHIC] tag represent manifestations of warp powers. | **`[SUSTAINED HITS]`** | 24.36 | Critical hits generate X additional hits on the target. | Each time an attack is made with a [SUSTAINED HITS X] weapon, a Critical Hit scores X additional hits on the target unit in addition to the normal hit. |
| **`[TORRENT]`** | 24.37 | Cones of fire/acid/flame. Attacks automatically hit the target without rolling. | Weapons with [TORRENT] project continuous streams of fire, acid, or gas. | **`[TWIN-LINKED]`** | 24.38 | Paired weapon synchronization. You can re-roll all Wound rolls made with this weapon. | Weapons with [TWIN-LINKED] feature synchronized barrels or power conduits. Each time an attack is made with a [TWIN-LINKED] weapon, you can re-roll the Wound roll. |

## 2. Core Unit Abilities (Section 24)

Core unit abilities represent innate traits common across diverse factions.

| Ability | Ref | Summary | Full Rules Description |
| :--- | :---: | :--- | :--- |
| **`DEADLY DEMISE`** | 24.08 | Explodes upon destruction, inflicting mortal wounds on nearby units. | From detonating ammunition to the death throes of colossal beasts, some units violently erupt when destroyed. When a model with DEADLY DEMISE X is destroyed, roll one D6 before removing it from play. On a 6, each unit within 6" suffers X mortal wounds. |
| **`DEEP STRIKE`** | 24.09 | Can start in Reserves and arrive anywhere on the battlefield >9" from enemies. | During deployment, you can set up this unit in Reserves instead of setting it up on the battlefield. In the Reinforcements step of one of your Movement phases, you can set up this unit anywhere on the battlefield that is more than 9" horizontally away from all enemy models. |
| **`FEEL NO PAIN`** | 24.12 | Post-damage roll to shrug off suffered wounds on X+. | Each time a model with FEEL NO PAIN X+ suffers damage and would lose a wound, roll one D6. On an X+, that wound is not lost. Can be rolled against normal and mortal wounds. |
| **`FIGHTS FIRST`** | 24.13 | Unit is eligible to fight in the Fights First step before standard combat. | Units with FIGHTS FIRST are eligible to fight in the Fights First step of the Fight phase, before players alternate selecting eligible units to fight. |
| **`FIRING DECK`** | 24.14 | Embarked passengers can fire up to X ranged weapons from the transport. | Each time a TRANSPORT model with FIRING DECK X is selected to shoot, you can select up to X ranged weapons equipped by passengers embarked within it. This transport model is treated as being equipped with those weapons until that shooting is resolved. |
| **`HOVER`** | 24.17 | Aircraft can opt to lose Aircraft rules and function as a standard Flyer. | Before the battle, in the Declare Battle Formations step, you can select for this AIRCRAFT model to Hover. If it does, its Move characteristic becomes 20", it loses the AIRCRAFT keyword, and it no longer follows the Aircraft rules. |
| **`INFILTRATORS`** | 24.20 | Can deploy anywhere outside the enemy deployment zone >9" from enemies. | During deployment, a unit with INFILTRATORS can be set up anywhere on the battlefield that is more than 9" horizontally away from the enemy deployment zone and all enemy models. |
| **`LEADER`** | 24.22 | Can attach to eligible Bodyguard units. In 11th edition, each bodyguard unit can have up to one LEADER and one SUPPORT unit attached. |
| **`LONE OPERATIVE`** | 24.24 | Cannot be targeted by ranged attacks from more than 12" away (or X" if specified). | Unless part of an attached unit, this unit can only be selected as the target of a ranged attack if the attacking model is within 12" (or the specified range X"). |
| **`SCOUTS`** | 24.31 | Pre-battle scout move of up to X" before the first turn begins. | Units with SCOUTS X" can make a normal move of up to X" before the first battle round begins. If both players have Scout units, players alternate resolving Scout moves starting with the first turn player. |
| **`STEALTH`** | 24.33 | Distorts targeting. -1 to Hit rolls made by enemy ranged attacks against this unit. | Each time a ranged attack is made against a unit with STEALTH, subtract 1 from the Hit roll. |

| **`DAMAGED`** | 24.39 | Degrading performance characteristics when reduced to below half wounds. | While this model has fewer than half its starting wounds remaining, its characteristics degrade (typically -1 to Hit rolls and/or reduced Objective Control). |

## 3. Battlefield Roles & Organizational Categories

Every unit in Warhammer 40k belongs to one primary battlefield role which dictates army roster limits and detachment composition.

| Keyword | Classification | Rules Impact & Limits |
| :--- | :--- | :--- |
| **`EPIC HERO`** | Unique Character | Max **1 instance** per specific Epic Hero datasheet per army. Cannot take standard Enhancements. |
| **`CHARACTER`** | Heroic Leader | Eligible to be designated as the army's **WARLORD**. Eligible to take Detachment Enhancements. |
| **`BATTLELINE`** | Core Troops | Increased datasheet limit: **Double standard limit** (4 in Incursion, 6 in Strike Force). |
| **`DEDICATED TRANSPORT`** | Squad Transport | Increased datasheet limit: **Double standard limit**. **Must** start battle with an embarked unit. |
| **`INFANTRY`** | Foot Soldiers | Standard models. Can traverse Breachable ruins and board Transports based on model type. |
| **`MOUNTED`** | Cavalry / Bikers | Fast units mounted on mechanical or beast steeds. Cannot move through breachable walls. |
| **`MONSTER`** | Colossal Beasts | Uses Big Guns Never Tire rules; can shoot and be shot at in Engagement Range. |
| **`VEHICLE`** | Armoured War Machines | Uses Big Guns Never Tire rules; subject to vehicle frame and hull measurement rules. |
| **`AIRCRAFT`** | Atmospheric Fliers | Starts in Reserves, compulsory minimum flight speed, restricted engagement, optional Hover mode. |
| **`FORTIFICATION`** | Static Defences | Cannot move, cannot embark, cannot be placed in Strategic Reserves. |

## 4. Movement, Scale & Characteristic Keywords

| Keyword | Description & Interactions |
| :--- | :--- |
| **`FLY`** | Ignores terrain and models when making normal, advance, or fall-back moves. |
| **`TITANIC`** | Huge scale war engines. Cannot be blocked or trapped by non-Titanic models. |
| **`TOWERING`** | Looms high over battlefield terrain. Governs line of sight through obscuring terrain. |
| **`WALKER`** | Agile bipedal/multipedal vehicles that can step over low terrain. |
| **`PSYKER`** | Wields warp powers. Vulnerable to `[ANTI-PSYKER]` weapon attacks. |
| **`GRENADES`** | Grants access to the *Grenade* core stratagem to inflict mortal wounds. |
| **`SMOKE`** | Grants access to the *Smokescreen* core stratagem for Benefit of Cover and Stealth. |

## 6. Frontend JSON Usage Guide

To use the keywords compendium in the frontend application:
```typescript
import keywordsData from './keywords.json';

// Find keyword tooltip description
export function getKeywordDetails(keywordName: string) {
  const normalized = keywordName.trim().toUpperCase();
  return keywordsData.allKeywordsList.find(k => 
    k.name.toUpperCase() === normalized || 
    k.name.toUpperCase() === `[${normalized}]`
  );
}
```
